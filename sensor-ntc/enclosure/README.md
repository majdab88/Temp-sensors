# sensor-ntc v2 enclosure

Parametric FreeCAD model of the v2 sensor enclosure: **2× AA (L91) battery bay
underneath, PCB deck above, screwed bottom door, screwed and gasketed lid.**

The model is generated by macros rather than drawn by hand, so every dimension
traces back to a named parameter. The `.FCStd` document is a build artifact and
is not versioned — rebuild it from these macros.

## Build it

Point FreeCAD's macro path at this folder (Edit → Preferences → Python → Macro),
then run **`build-all.FCMacro`** and File → Save As.

It chains four steps, which can also be run individually:

| macro | what it does |
|---|---|
| `sensor-ntc-v2-enclosure.FCMacro` | new document with `Body_Main`, `Body_Lid`, `Body_Door` and the `params` spreadsheet |
| `round-rims.FCMacro` | fillets the horizontal rims (lid top, door underside, body bottom) |
| `assembly.FCMacro` | wraps the parts in an `Enclosure` container and adds the `explode` parameter |
| `tidy-view.FCMacro` | hides sketches and superseded features so only the finished solids show |

## Changing dimensions

**Edit the `params` spreadsheet — no rebuild.** Sketch constraints and feature
lengths are bound to it by expression, so the model follows. `explode` opens the
assembly for a look inside; `0` closes it.

**Rebuild only for structural changes** — different sketch geometry, or a new
feature. Those live in the macro source.

Corner rounding is built into the sketches rather than applied as PartDesign
Fillets, because a Fillet stores the edge names it was given and those shift
whenever an upstream dimension changes, which silently freezes the whole body.
The rim fillets are the exception; if one ever shows as Invalid, re-run
`round-rims.FCMacro`.

## Before printing

- `bay_l` and the `slot_*` values are placeholders — set them from the datasheet
  of whichever leaf contacts you use, and test-print the bay alone first.
- Material: PETG, ABS or ASA. Not PLA: the contacts keep the plastic under
  permanent spring load and PLA turns brittle at freezer temperatures.
- Fasteners: M2 × 10 mm for the lid, M2 for the door, M2.5 into the PCB
  standoffs (the board's holes are 2.5 mm).
- Gasket: 2 mm silicone cord in the lid groove. Set `ADD_GASKET = False` in the
  build macro for a plain lid sealed with foam tape instead.

## Reference geometry

The build loads `esp32c6.step` (the KiCad board export) to position the ghost
PCB, and the PCB standoffs are placed on the board's real mounting holes taken
from `NTC_SENSOR.kicad_pcb`. Both are kept as local inputs and are listed in the
repository root `.gitignore`. Without the STEP the build still works and falls
back to a plain box for the reference board.

`sensor-ntc-v2-enclosure.scad` is the original OpenSCAD model. It is superseded
by the FreeCAD macros and is behind on several features; it is kept only for
reference.
